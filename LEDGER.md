Rule: one change at a time; back up before modifying; record exact command, why, before/after metrics, verdict, revert.

**Build and install (root-owned)** (rows 13/14; full text and uninstall in REPORT.md §2): `gcc -O2 -o tsc-resync tools/tsc_resync.c`, then `sudo install -o root -g root -m 0755 tsc-resync /usr/local/bin/tsc-resync`, the unit with `-m 0644` into `/etc/systemd/system/` and the hook with `-m 0755` into `/usr/lib/systemd/system-sleep/`; verify with `stat -c '%U:%G %a %n' <files>` that each is `root:root`. The unit runs as root at every boot and the hook at every resume: never install into a user-writable directory. Needs the `msr` module (this repo ships no modules-load drop-in; remove any you add when reverting), taints the kernel, and is blocked by Secure Boot/lockdown. AMD Zen 4 tested only. Row 13 ran the tool straight from the repo checkout with sudo for the experiment; do not make that your installed copy.
