# Validation — analysis half

Scope: `detector/analyze/` (hitch detection, periodicity, correlation, statistics,
reporting, compare, fixed, selftest). The **live Dota 2** validation (spec Validation b/c)
belongs to the trial/collectors work and is **not** covered here — this file records the
**synthetic** evidence obtained with the real code.

## Environment

* CachyOS, Linux 6.18.55-1-cachyos-lts, Ryzen 9 7945HX, RTX 4080 Laptop.
* `python3` with numpy 2.5.3, scipy 1.18.1, matplotlib 3.11.2, pytest 9.1.1.
* Plots via headless `Agg`. No Dota launched, no GUI driven.

## How to reproduce

```sh
python3 -m pytest detector/analyze/tests    # 17 unit tests
./bin/stutter selftest --seeds 50 --scenario-seeds 12 --n-perm 300 --out /tmp/selftest
```

### Unit tests

`17 passed` (deterministic, synthetic, no Dota). Cover: rolling-median centre exclusion,
detection + FLOOR, 100 ms merging, sub-floor rejection, fps lows, effect sizes/bootstrap
CI, precision/recall edge cases, periodic vs random vs sparse-vs-short-window
periodicity, run-dir contract loading, correlation finding/ignoring signals,
`analyze_run` + outputs, `fixed`, `compare`, and the `synth`/`detect` CLI.

### Self-test (ground truth)

`stutter selftest --seeds 50 --scenario-seeds 12 --n-perm 300` → **147/147 assertions
passed**. Synthetic traces at 144 fps (jitter σ=0.3 ms, plus sub-floor 10 ms noise
spikes); injected hitches 45-75 ms; p-values over 300 permutations.

| scenario | truth | runs | recovered period | max deviation | precision | recall | kind |
|---|---|---|---|---|---|---|---|
| periodic | 4.0 s | 12 | 4.00 s (all) | 0.00% | 1.000 | 1.000 | periodic (12/12) |
| sparse | 45.0 s | 12 | 44.44 s (all) | 1.23% | 1.000 | 1.000 | sparse (12/12) |
| mixed | 4.0 s + 45 s | 12 | 4.00 s (steady) | 0.00% | 1.000 | 1.000 | mixed (12/12) |
| clean (no hitches) | — | 50 | — | — | — | — | **0/50 flagged** |

* **False-positive rate on clean traces: 0/50 = 0.0000**; mean false hitches/run = 0.000.
* Precision/recall ≥ 0.95 requirement met in **every** run of every scenario (all exactly
  1.000 on these truth-above-floor hitches).
* Sparse periods land at 44.44 s because the 100 ms spectral snap grid is coarse; the
  1.23% deviation is inside the +-5% requirement and the interval-based estimate is exact
  to the sampling.

### Warm-up exclusion

A run with hitches **during** warm-up (`schedule_from_t0`, warm-up 20 s): ground truth
5 pre / 25 post; detected **0 pre / 25 post** → pre-warm-up hitches are excluded, all
post-warm-up hitches recovered.

### Sensitivity to K and FLOOR

`clear` = 55 ms periodic hitches (high contrast). `marginal` = 18 ms periodic hitches
just above the default FLOOR, with 14 ms noise spikes ~12/min. `false_positives` is the
count on a clean 160 s run.

| axis | value | clear prec / recall | marginal prec / recall | clean FP |
|---|---|---|---|---|
| K | 2.0 | 1.000 / 1.000 | 0.603 / 1.000 | 0 / 0 |
| K | 2.5 (default) | 1.000 / 1.000 | 1.000 / 0.857 | 0 / 0 |
| K | 3.0 | 1.000 / 1.000 | n/a / 0.000 | 0 / 0 |
| K | 3.5 | 1.000 / 1.000 | n/a / 0.000 | 0 / 0 |
| K | 4.0 | 1.000 / 1.000 | n/a / 0.000 | 0 / 0 |
| FLOOR | 10.0 ms | 1.000 / 1.000 | 1.000 / 0.857 | 0 / 0 |
| FLOOR | 13.9 ms (default) | 1.000 / 1.000 | 1.000 / 0.857 | 0 / 0 |
| FLOOR | 17.5 ms | 1.000 / 1.000 | 1.000 / 0.800 | 0 / 0 |
| FLOOR | 21.0 ms | 1.000 / 1.000 | n/a / 0.000 | 0 / 0 |
| FLOOR | 25.0 ms | 1.000 / 1.000 | n/a / 0.000 | 0 / 0 |

Interpretation: on high-contrast hitches the detector is insensitive to K/FLOOR (as it
should be). On **marginal** hitches, raising K above ~2.5 (i.e. `K*median > 18 ms`) or
FLOOR above ~18 ms starts to **miss** real hitches (recall → 0), while lowering K to 2.0
starts to **catch near-floor noise** (precision 0.60). This is why the default
`K=2.5 / FLOOR=13.9 ms` is the chosen operating point and why these must be re-tuned on
real Dota traces (see below). Note: with the default K=2.5 the 14 ms noise spikes never
pass `K*median ≈ 17.4 ms`, so no false positives appear even at FLOOR=10 ms here.

### Correlation check (spot, synthetic)

On a mixed synthetic run with GPU-clock dips on ~60% of hitches, PSI-CPU spikes on ~40%,
mem-dirty spikes on ~30%, and a decoy random walk, the ranked table puts
`gpu.sm_clock_mhz` (z≈-40), `cpu.psi_cpu_some_avg10` (z≈+20), `sys.mem_dirty_mb`
(z≈+15) at the top and the decoy well below; the two seeded log templates
(`nvidia ... Xid ...`, `pipewire: xrun`) are enriched near hitches while unrelated
kernel/journal noise is not. See the report artifact generated by `stutter report`.

## Not yet validated (and what it needs)

* **Live Dota 2** numbers: run-to-run variance of hitches/min and 1%/0.1% lows, and the
  final K/FLOOR, require the baseline runs (spec Validation c) — owned by the trial work.
* **Collector overhead** and MangoHud column mapping are the collectors half.
* The synthetic truth assumes single-frame stalls; real stalls are usually longer bursts.
  Longer bursts only make detection easier, but the merging/precision behaviour on real
  bursty traces is unmeasured.
* `fixed_def.json` thresholds are **PROVISIONAL** until the baseline variance study
  lands; see [`docs/FIXED-DEFINITION.md`](FIXED-DEFINITION.md).
